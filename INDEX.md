# Arbol Trunk: Catalog

- [`trunks/trivial/specs/`](trunks/trivial/specs/README.md): the Trivial Trunk (`TRV`), code name `trivial`: one Driver run for each Chat Exchange, the default Trunk of every Root.
- [`trunks/steady/specs/`](trunks/steady/specs/README.md) holds the draft requirements for the Steady Trunk (`STE`), code name `steady`, intended as Arbol's primary Trunk for everyday chat work.

## Conventions

- Every artifact goes into a chapter folder, never directly into the corpus root. `README.md`, `INDEX.md` and a `GLOSSARY.md` are the exceptions.
- List a chapter here when it is created.
